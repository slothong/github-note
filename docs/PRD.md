# GitHub Note - Product Requirements Document

## 1. 개요

GitHub 저장소를 백엔드 저장소로 활용하는 마크다운 노트 앱. 별도 서버 없이 GitHub API를 통해 노트를 읽고, 쓰기하며, 변경사항을 커밋/푸시하는 Electron 데스크톱 앱이다.

### 핵심 가치
- **서버리스**: GitHub 자체가 저장소이자 백업이자 버전 관리 시스템
- **마크다운 네이티브**: `.md` 파일을 그대로 다루므로 앱 밖에서도 접근 가능
- **간결함**: 노트 작성에 필요한 최소한의 기능만 제공

## 2. 사용자 플로우

```
앱 실행 → GitHub 로그인 → 레포 선택 → 노트 목록 표시
                                         ↓
                               노트 선택 → 마크다운 편집/미리보기
                                         ↓
                               저장 → 커밋 & 푸시
```

## 3. 기능 요구사항

### 3.1 인증

| 항목 | 설명 |
|------|------|
| 로그인 방식 | GitHub OAuth (Device Flow) |
| 필요 권한 | `repo` (private repo 접근 포함) |
| 토큰 저장 | OS keychain (Electron `safeStorage`) |
| 로그아웃 | 토큰 삭제 후 로그인 화면으로 복귀 |

> **Device Flow를 사용하는 이유**: Electron 앱에서 별도 서버 없이 OAuth를 처리할 수 있는 가장 안전한 방식. 사용자가 브라우저에서 코드를 입력하는 형태.

### 3.2 레포 선택

- 로그인 후 사용자의 레포 목록을 표시 (owner 기준, 최근 업데이트순)
- 검색으로 레포 필터링
- 선택한 레포는 기억하여 다음 실행 시 자동 진입
- 레포 전환 기능 제공

### 3.3 노트 탐색

- 선택한 레포의 **기본 브랜치**에서 `.md` 파일 목록을 트리 구조로 표시
- 폴더 구조 그대로 반영
- 파일/폴더 이름 기준 검색

### 3.4 노트 편집

| 기능 | 설명 |
|------|------|
| 에디터 | 마크다운 텍스트 에디터 (코드 하이라이팅 포함) |
| 미리보기 | 실시간 마크다운 렌더링 (split view) |
| 자동 저장 | 로컬 임시 저장 (편집 중 앱 종료 대비) |

### 3.5 노트 CRUD

| 동작 | GitHub API 매핑 |
|------|-----------------|
| **생성** | 새 `.md` 파일 생성 → 커밋 |
| **읽기** | Contents API로 파일 내용 fetch |
| **수정** | 파일 내용 업데이트 → 커밋 |
| **삭제** | 파일 삭제 → 커밋 |
| **폴더 생성** | 폴더 내 파일 생성 시 자동 생성 |

### 3.6 저장 & 동기화

- **저장 버튼** 클릭 또는 `Cmd+S`로 커밋 & 푸시
- 커밋 메시지 자동 생성 (예: `Update note-title.md`)
- 커밋 메시지 직접 입력 옵션
- 충돌 시: 원격 변경사항 감지 후 사용자에게 알림 (덮어쓰기 / 원격 내용으로 갱신 선택)

## 4. 기술 스택

| 영역 | 기술 |
|------|------|
| 프레임워크 | Electron + TypeScript |
| 렌더러 | React |
| 마크다운 에디터 | CodeMirror 6 |
| 마크다운 렌더링 | remark + rehype |
| GitHub API | Octokit (REST) |
| 인증 토큰 저장 | Electron safeStorage |
| 스타일링 | Tailwind CSS |
| 빌드 | electron-builder |

## 5. 화면 구성

### 5.1 로그인 화면
- GitHub 로그인 버튼
- Device Flow 코드 표시 및 브라우저 열기 안내

### 5.2 레포 선택 화면
- 레포 목록 (검색 포함)
- 각 레포의 이름, 설명, public/private 표시

### 5.3 메인 화면 (3-panel 레이아웃)
```
┌──────────┬────────────────────────────────┐
│          │                                │
│  사이드바  │         에디터 / 미리보기         │
│  (파일   │                                │
│   트리)   │                                │
│          │                                │
│          │                                │
└──────────┴────────────────────────────────┘
```
- **사이드바**: 파일 트리 + 새 노트/폴더 버튼
- **에디터 영역**: 마크다운 편집 / 미리보기 토글 또는 분할

## 6. 비기능 요구사항

- 오프라인 시 로컬 편집 가능, 온라인 복귀 시 푸시
- GitHub API rate limit 고려 (조건부 요청, ETag 활용)
- 대용량 파일(1MB 초과) 경고 표시

## 7. MVP 범위

**Phase 1 (MVP)**
1. GitHub 로그인/로그아웃
2. 레포 선택
3. 마크다운 파일 목록 조회 (트리)
4. 노트 조회 & 편집
5. 노트 생성 & 삭제
6. 저장 시 커밋 & 푸시

**Phase 2 (이후)**
- 이미지 업로드 (드래그 앤 드롭)
- 노트 간 링크 (`[[wiki-link]]` 스타일)
- 전체 텍스트 검색
- 다크 모드
- 복수 브랜치 지원
- 오프라인 모드 고도화

## 8. 제약 사항

- GitHub API Contents API는 단일 파일 1MB 제한이 있음 → 초과 시 Blob API 사용
- Device Flow는 GitHub App 또는 OAuth App 등록이 필요 → 앱 배포 시 Client ID 필요
- 동시 편집 미지원 (단일 사용자 데스크톱 앱)
